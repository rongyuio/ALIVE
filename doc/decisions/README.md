## 写一份新决策

包含这几节，缺一不可：

- **状态**：提议 / 已决定 / 已取代 / 已废止
- **背景**：什么问题逼出了这个决策，不写的话一年后没人知道为什么
- **候选**：至少两个，每个的代价
- **决策**：选了哪个，为什么
- **后果**：这个选择让我们失去了什么
- **复查条件**：什么情况下该重新考虑

"后果"和"复查条件"不是形式主义。一个只写优点的决策记录，等于没记录。
